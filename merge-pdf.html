Merge PDF Files Online for Free

Need to combine several documents into one file? FreePDF's Merge PDF tool lets you select multiple PDF files and combine them into a single PDF right in your browser.

Merge PDF files

Before you start: Keep the PDF files you want to combine ready on your device. Choose multiple files when the tool opens, then select Merge PDFs.

How to merge PDF files

  1. Open the FreePDF Merge PDF tool using the button above.
  2. Select two or more PDF files from your device.
  3. Choose Merge PDFs to combine the selected files.
  4. Download the resulting PDF when processing finishes.
