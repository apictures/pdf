Contact FreePDF

We welcome reports about broken tools, conversion problems, accessibility issues, and ideas for improvements.

Report a problem or request a feature

FreePDF is maintained as a public GitHub project. You can report a problem or suggest a feature through the project issue tracker:

Visit FreePDF issue tracker ↗

What to include

  • The tool you were using.
  • Your browser and operating system.
  • The steps that caused the problem and any error message.
  • A sample file only if it is safe to share publicly. Never post confidential or personal documents.

Please do not share passwords, sensitive personal information, or private documents in public issues.
